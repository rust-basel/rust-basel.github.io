# Rust Basel Meetup #14 – Open-Source Evening

Our 14th on-site meetup, generously sponsored and hosted by [Optravis LLC](https://optravis.com) at Barfüsserplatz 6, Basel.

A night with a lot of fun and getting to know each other while making meaningful contributions.

### 🔧 A Different Kind of Meetup

This time we switched things up: instead of the usual talk format, we spent the evening making real contributions to Rust open-source projects.

Here's how it worked: everyone who brought an issue or project gave a short pitch to the group. Then we voted on which ones to work on together. Any project that only one person wanted to tackle got dropped from the list — the whole point was to collaborate, after all. We ran several rounds of this until the field narrowed down, and after three rounds of voting we ended up with four groups, each tackling a different open-source Rust project.

From there we just dove in — pairing up, reading code, opening PRs, and getting to know each other along the way. It was a great reminder that open-source contribution doesn't have to be a solo endeavour.

The format was inspired by the [Hackergarten Basel](https://hackergarten.net/) — another great tech meetup in Basel worth checking out!

### 🍕 Community + Pizza

Pizza, drinks, and good company made for a relaxed and productive atmosphere. New faces mixed with regulars, and the conversations kept going long after the coding wrapped up.
